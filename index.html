Pacchetti personali — carica tuoi algoritmi, scale, arpeggi e accordature (JSON)

Un pacchetto è un file JSON (lo stesso formato di stock.json) che può contenere algorithms, scales, arpeggios, tunings. Incolla il testo qui sotto oppure carica un file .json; i pacchetti restano salvati nel browser.

    Tipi di algoritmo
    • path – percorso ascendente di note successive, una corda alla volta, con vincoli (note per corda, salto di corde, ampiezza in tasti, ordine dei gradi…). I campi {"$param":…} diventano controlli per l'utente.
    • window – finestra di tasti ancorata alla fondamentale su una corda (principio delle forme CAGED).
    • shape – forma fissa traslabile: per ogni corda gli scostamenti rispetto al tasto della fondamentale.
    • script – avanzato: code è il corpo di una funzione (ctx, params, H). Esegui solo script di cui ti fidi.
    Ogni algoritmo può avere appliesTo: {"kinds":["scale"],"minNotes":5,"maxNotes":8}.
