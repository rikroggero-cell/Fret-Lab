Imposta la password

Scegli una password: questa pagina genera il contenuto del file auth.js. La password non viene salvata né inviata da nessuna parte; nel file finisce solo la sua impronta (hash).

Poi, su GitHub: apri il file auth.js nel repository, clicca la matita (Edit), sostituisci tutto il contenuto con il testo generato e premi Commit changes. Per togliere la password rimetti window.FL_AUTH = null;.
